# The Rob You Want

A single-file, free, private-to-the-phone comfort chat. Open `index.html` — no build step.

- AI: Pollinations free tier (no key). Measured limit: 1 reply every 45 s per IP; the app waits and retries, and falls back to built-in replies when offline.
- Everything (chat, Pocket, Ledger, photo) is saved only in the phone's browser. On iPhone, add it to the Home Screen so Safari doesn't clear it.
- Hosted with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
